# Créditos — recursos de la Residencia Demo 360°

Todos los recursos externos provienen de [Poly Haven](https://polyhaven.com) y están bajo licencia **CC0 (dominio público)**. El resto de la geometría (arquitectura, cocina, baño, cama, sofás, mesas, sillas, reposeras) se modeló por script en Blender. El cielo es el Sky Texture procedural de Blender (sin HDRI).
